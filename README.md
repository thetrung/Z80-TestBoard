# Z80-TestBoard
Another test-NOP board for Z80 without SRAM but PIC18F4520 feeding DATA.

### Note
A Strip-off version of Z80-Debugger but: 
- No SRAM
- No MicroSD
- Feeding DATA from UART
- Display State from I2C Display
