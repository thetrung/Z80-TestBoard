# Z80-TestBoard
Another test-NOP board for Z80 with NE555P.

### Note
A Strip-off version of Z80-Debugger but nothing rather than :
- Z80-NOP testboard for PLCC-44 package
- SOP28-DIP28 socket converter
- Tiny LED 5V power board
